Buyzo – E-Commerce Platform

**Buyzo** is a modern Django-based e-commerce web application designed to provide a convenient online shopping experience across multiple product categories.

The project aims to build a multi-vendor e-commerce platform with a clean user interface, organized product management, and a scalable web application structure.

Project Overview

Buyzo is being developed using Django and modern frontend technologies. It combines an attractive shopping interface with a Python-based backend.

Key Features

- Modern and responsive e-commerce interface
- Organized project structure using Django
- Product category management
- User authentication module
- Static asset management
- SQLite database integration
- Multi-vendor e-commerce platform concept

Note: Features are under development. The final functionality will depend on the ongoing implementation.

Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/Harshiii81/Buyzo-Ecommerce.git
```

2. Navigate to the project directory

```bash
cd Buyzo-Ecommerce
```

3. Create a virtual environment

```bash
python -m venv venv
```

4. Activate the virtual environment (Windows)

```bash
venv\Scripts\activate
```

5. Install Django

```bash
pip install Django==6.1.2
```

Install any additional project dependencies required by the application.

6. Apply database migrations

```bash
python manage.py migrate
```

7. Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
